# REALITY x25519-dalek 3.0.0 upgrade

Date: 2026-09-23. Dedicated branch: `chore/x25519-dalek-3`.
Parent: `26f3efe5946dbe96410e85b8541ccf5fe7c244a5` (rustls 0.23.45).

## Scope and compatibility

The library's optional REALITY dependency and the independent hybrid probe now
use registry x25519-dalek 3.0.0, with defaults disabled and `static_secrets` /
`zeroize` explicitly enabled. No REALITY handshake, provider, key lifetime,
fallback policy or third-party source is changed. Ring still supplies entropy.
The upstream example provider and its HPKE dependency retain their upstream
2.x/rand_core 0.6 requirements; those are not the library's normal dependency
graph. This deliberately avoids rewriting unrelated upstream examples or crypto
adapters. Both the example and Bogo still compile.

The [official changelog](https://docs.rs/crate/x25519-dalek/3.0.0/source/CHANGELOG.md)
raises the dependency's MSRV to Rust 1.85 and removes the secret types' explicit
`Zeroize` implementation, while retaining zeroization on drop with `zeroize`.
The fork uses `StaticSecret::from`, `PublicKey::from` and `diffie_hellman`, not the
changed RNG/`Zeroize` APIs. Its explicit temporary-byte clearing remains intact.
The [3.0.0 implementation](https://docs.rs/crate/x25519-dalek/3.0.0/source/src/x25519.rs)
clears `StaticSecret` and `SharedSecret` on drop. This is source/feature review,
not an assertion made by reading freed memory. The fork documents the conditional
1.85 minimum without raising the upstream non-REALITY baseline. Tests below use
Rust 1.98.1, not an MSRV execution test.
